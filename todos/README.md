# Feature todos

Ideas for Redhot, in the order I'd build them. Each file says what the feature is, why it's worth it, how it could work in Redhot (a terminal search window plus the Swift menu bar helper) and roughly how big it is.

## Top picks

1. ~~[Script commands](01-script-commands.md)~~ ✅ built: run a folder of scripts with `@redhot.` headers
2. ~~[File search](02-file-search.md)~~ ✅ built: find files with Spotlight's `mdfind`
3. ~~[System commands](03-system-commands.md)~~ ✅ built: lock, sleep, empty Trash, dark mode and more
4. ~~[Kill a process or port](04-kill-process-or-port.md)~~ ✅ built: stop an app, a process or whatever holds a port
5. ~~[Web search fallback](05-web-search-fallback.md)~~ ✅ built: search the web when nothing matches

## Skipped for now

- **AI chat:** it needs API keys and doesn't feel native in a terminal.
- **An extension store:** script commands give most of the benefit with none of the platform work.
- **Calendar:** it needs calendar permission and a lot of interface.

Effort is a rough guess: small is a day or less, medium a few days, large a week or more.
